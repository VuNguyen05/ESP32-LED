
## Phần cứng 

1. ESP32 Devkit v1
2. 01 Đèn LED.
3. 01 Điện trở $1000\Omega$.
4. 01 Nút bấm 4 chân.
5. Breadboard và dây cắm.

## Yêu cầu chức năng
- Nhấn đơn (Single Click): Bật hoặc Tắt đèn LED (ngắt chế độ nhấp nháy nếu đang chạy).
- Nhấn kép (Double Click): Chuyển sang chế độ nhấp nháy LED (chu kỳ 500ms sáng / 500ms tắt).
